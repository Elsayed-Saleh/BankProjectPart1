# Bank Management System Part1

A console-based Bank Management System developed using C++.

## 📌 Description

This project is a simple Bank Management System that allows users to manage client information through a console-based menu.

The application stores client data in a text file and provides several operations for managing accounts.

## ✨ Features

- Display all clients
- Add a new client
- Delete a client
- Update client information
- Find a client by account number
- Prevent duplicate account numbers
- Store client data in a text file
- Load client data from the file
- Display client information in a formatted way

## 📋 Client Information

The system stores the following information for each client:

- Account Number
- PIN Code
- Name
- Phone Number
- Account Balance

## 🗂️ Main Menu

The application provides the following options:

1. Print All Clients
2. Add New Client
3. Delete Client
4. Update Client Information
5. Find Client
6. Exit
